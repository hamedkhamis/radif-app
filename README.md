# ردیف 2

اپ اندروید ساده برای کارهای روزانه با یادآوری سخت‌گیر.

## امکانات

- لیست کارهای امروز با چک‌باکس و دکمه + برای اضافه کردن
- هر کار: ساعت یادآوری دلخواه، تکرار (یک بار، هر روز، شنبه تا چهارشنبه، روزهای دلخواه)، کار اصلی با ستاره
- یادآوری تا جواب ندی تکرار می‌شه (هر ۱۰ دقیقه، تا ۳ یا ۶ بار) و نوتیفیکیشن قابل کنار زدن نیست
- «امروز نشد»: کار یک‌باره می‌ره برای فردا، کار تکراری امروز رد می‌شه
- حالت تمرکز: ۲۵ دقیقه تایمر زنده توی نوتیفیکیشن، بعدش ۵ دقیقه استراحت
- پارکینگ: هر فکر یا سؤال متفرقه رو سریع بنویس، بعداً تبدیل به کار کن یا حذف کن
- آمار: کارهای انجام‌شده، استریک (پنجشنبه و جمعه استریک رو نمی‌شکنن)، دورهای تمرکز

کارهای پیش‌فرض: شروع کار اصلی ۱۰:۰۰، تماس‌های بی‌پاسخ ۱۶:۳۰، بستن روز ۱۷:۴۵، گوشی بیرون اتاق خواب ۲۳:۳۰.

## ساخت APK با GitHub Actions

1. یه ریپوی جدید بساز و همه فایل‌های این پوشه رو آپلود کن.
2. توی Actions، ورک‌فلو «Build APK» رو اجرا کن.
3. فایل `radif-apk` رو از Artifacts دانلود، از زیپ دربیار و نصب کن.

اگه نسخه قبلی نصبه، اول حذفش کن (هر بار ساخت امضای متفاوتی داره).
