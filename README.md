# ردیف

اپ اندروید ساده برای یادآوری سه کار روزانه، شنبه تا چهارشنبه:

1. شروع کار اصلی (پیش‌فرض ساعت ۱۰:۰۰)
2. برگشت به تماس‌های بی‌پاسخ (پیش‌فرض ۱۶:۳۰)
3. بستن روز و نوشتن کار فردا (پیش‌فرض ۱۷:۴۵)

نوتیفیکیشن هر ۱۰ دقیقه تکرار می‌شه (حداکثر ۶ بار) تا روی «انجام شد» یا «امروز نشد» بزنی. نوتیفیکیشن قابل کنار زدن نیست.

## ساخت APK با GitHub Actions

1. یه ریپوی جدید توی گیت‌هاب بساز و همه فایل‌های این پوشه رو داخلش آپلود کن.
2. برو به Actions و ورک‌فلو «Build APK» رو اجرا کن (یا فقط push کن).
3. بعد از تموم شدن، فایل `radif-apk` رو از بخش Artifacts دانلود کن، از زیپ دربیار و نصب کن.

## بعد از نصب

دکمه‌های ۱ و ۲ و ۳ توی صفحه اول رو بزن، بعد «تست همین الان». روی شیائومی حتماً شروع خودکار رو روشن کن و صرفه‌جویی باتری رو روی «بدون محدودیت» بذار.
